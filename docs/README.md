# HumDAV

Synchronize HumHub contacts to mobile devices and desktop clients through **read-only CardDAV**. HumDAV provides address books for visible users, followed users and shared spaces, revocable device tokens, automatic discovery, and configuration profiles for iOS and macOS. Apple profiles can optionally include the Calendar module's native CalDAV service.

Personal fields respect the requesting user's **View your about page** permission and HumHub's profile-field visibility. Optional data exports are disabled by default. E-mail also requires an explicit administrator setting and a visible E-mail profile field. CardDAV transfers contact data to external devices, where copies may remain after server-side access is revoked.
